# Roadmap

## Public Web Demo

- Keep `index.html` working from GitHub Pages.
- Keep `index-6.html` available as the known working page.
- Keep `examples/demo-breaker.json` as the startup demo model.
- Keep `examples/basic-dancer-model.json` as a compatibility demo model.
- Improve first-run UI around model loading and microphone permissions.

## Model And Motion Formats

- Add explicit model-format versions.
- Add stronger JSON validation.
- Document training data separately from inference model data.
- Explore MediaPipe landmark exports.
- Explore normalized skeleton, bone vector, joint angle, and quaternion formats.

## Avatar And Visual Systems

- Improve avatar styles.
- Add better rig mapping for external avatars.
- Keep visual settings exportable with model JSON.
- Prepare BOW and WATTOO mapping experiments.

## Standalone / VJ

- Add fullscreen performance mode.
- Add show preset import/export.
- Research browser-source capture workflows.
- Research Spout, Syphon, NDI, and virtual camera output.
- Explore a lightweight local launcher or Tauri/webview wrapper.
